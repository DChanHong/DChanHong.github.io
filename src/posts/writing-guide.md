## 문제부터 기록합니다

어떤 상황에서 문제가 발생했는지, 누구에게 어떤 영향을 주었는지 설명합니다. **실제로 확인한 사실**과 앞으로 검증할 가설을 구분합니다.

> 이 글은 상세 화면을 확인하기 위한 샘플입니다. 실제 프로젝트 성과를 설명하지 않습니다.

## 선택한 방법과 이유

검토한 대안과 선택 이유를 기록하고, 핵심 구현을 코드로 보여줍니다.

```python
def should_retry(status_code: int) -> bool:
    """일시적인 오류만 재시도 대상으로 구분하는 예시."""
    return status_code == 429 or 500 <= status_code < 600
```

| 항목 | 기록할 내용 |
| --- | --- |
| 실행 조건 | 환경, 버전, 입력 데이터 |
| 검증 방법 | 기대 결과와 확인 방법 |
| 한계 | 아직 확인하지 못한 조건 |

## 결과와 다음 단계

실제로 측정한 결과를 정리합니다. 수치에는 측정 기간과 조건을 함께 적습니다.

- 코드와 재현 방법을 연결합니다.
- 이미지 파일은 `src/assets/images/`에 보관합니다.
- 글이 준비되면 파일 위쪽의 `draft`를 `false`로 바꿉니다.

기존 글을 이전할 때는 원래 작성일을 보존합니다.
